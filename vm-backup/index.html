Duke AQ VM Backup Retention

A private, single-user backup utility maintained by Trailokaya Raj Bajgain.

What it does

The utility archives backup-transfer records from a Windows virtual machine to the owner’s Google Drive. It downloads cloud archives and verifies their contents before removing eligible local copies, while retaining at least seven days locally.

It is designed to run as a scheduled task on the VM without requiring a Mac or Codex session. Google authorization and a successful verification run are required before cleanup is enabled.

Data access

Google Drive authorization is used to upload and independently download archives for verification. This public page contains no research data, backup links, or credentials.
